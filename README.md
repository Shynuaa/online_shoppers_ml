# Online Shoppers Purchase Prediction

## Описание проекта

Проект посвящён прогнозированию намерения пользователя совершить покупку в интернет-магазине на основе характеристик его сессии.

Решается задача бинарной классификации: модель определяет, завершится ли посещение сайта покупкой (`Revenue = True`).

В качестве алгоритма машинного обучения используется **Random Forest Classifier**.

## Датасет

Используется датасет [Online Shoppers Purchasing Intention](https://www.kaggle.com/datasets/henrysue/online-shoppers-intention).

Основные характеристики:
- Количество записей: 12 330.
- Количество признаков: 17.
- Целевая переменная: `Revenue`.
- Тип задачи: бинарная классификация.

Датасет содержит информацию о поведении пользователей на сайте: времени просмотра страниц, типе посетителя, источнике трафика, показателях отказов и других характеристиках сессии.

## Обучение модели

В качестве алгоритма используется Random Forest со следующими параметрами:

| Параметр | Значение |
|---|---:|
| n_estimators | 200 |
| max_depth | 15 |
| random_state | 42 |
| class_weight | balanced |
| n_jobs | -1 |

Для предварительной обработки данных используется единый ML-пайплайн:

- Числовые признаки: заполнение пропусков медианой и стандартизация.
- Категориальные признаки: заполнение пропусков наиболее частым значением и One-Hot Encoding.

Данные разделяются на обучающую и тестовую выборки в соотношении 80/20 с сохранением пропорций классов.

### Метрики качества

Для оценки модели используются:

- Precision
- Recall
- F1-score
- ROC-AUC
- PR-AUC

Основное внимание уделяется PR-AUC и F1-score, поскольку целевые классы несбалансированы.

Полученные результаты базовой модели:

| Метрика | Значение |
|---|---:|
| Precision | 0.646 |
| Recall | 0.644 |
| F1-score | 0.645 |
| ROC-AUC | 0.922 |
| PR-AUC | 0.710 |

## Запуск API

API реализовано с использованием FastAPI.

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск приложения

```bash
uvicorn app:app --host 0.0.0.0 --port 8000
```

### 3. Документация API

После запуска приложение доступно по адресу:

http://localhost:8000/docs

Основной endpoint:

`POST /predict`

Принимает характеристики пользовательской сессии и возвращает:
- `prediction` — предсказанный класс;
- `purchase_probability` — вероятность совершения покупки;
- `result` — текстовый результат классификации.

## Контейнеризация с помощью Docker

Для запуска модели в контейнере используется Docker.

### Сборка Docker-образа

```bash
docker build -t online-shoppers-model .
```

### Запуск контейнера

```bash
docker run -d -p 8000:8000 --name shoppers-api online-shoppers-model
```

### Проверка работы

Откройте в браузере:

http://localhost:8000/docs

Для остановки контейнера:

```bash
docker stop shoppers-api
```

Для удаления контейнера:

```bash
docker rm shoppers-api
```
